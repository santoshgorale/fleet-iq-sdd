# Checklist — Product Owner / Project Manager (`tasks.scope`)

## Traceability, both directions
- [ ] Every acceptance criterion maps to at least one task
- [ ] Every task maps back to a criterion
- [ ] The mapping is written in `tasks.md#traceability`, not held in your head
- [ ] Any task with no criterion is either removed or `spec.md` is updated

## Tasks are plannable
- [ ] Every task has an owner role
- [ ] Every task has a size — no "TBD"
- [ ] Anything sized L is split or spiked
- [ ] Dependencies between tasks are explicit

## Sequence
- [ ] A demonstrable increment exists early, not only at the end
- [ ] Integration risk is front-loaded
- [ ] Nothing critical is sequenced behind an unresolved external dependency

## External dependencies
- [ ] Each names a team **and** a person
- [ ] Each has a needed-by date
- [ ] Each says what happens if it slips

## Honesty
- [ ] Deferred scope recorded with reasons in `tasks.md#deferred`
- [ ] Scope added during slicing is reflected back into `spec.md`
- [ ] You would be comfortable showing this plan to the people funding it
